## Features

- JWT Authentication
- Multi-Tenant Architecture
- BullMQ Job Queue
- Redis Integration
- PostgreSQL with Prisma ORM
- Swagger API Documentation
- Docker Support
- GitHub Actions CI
- Integration Testing using Jest
- Environment Validation using Zod
- Structured Logging with Pino

---

## Tech Stack

| Layer | Technology |
|--------|------------|
| Backend | Node.js, Express |
| Database | PostgreSQL |
| ORM | Prisma |
| Queue | BullMQ |
| Cache | Redis |
| Authentication | JWT |
| Validation | Zod |
| Logging | Pino |
